## MVP (реализовано)

### Кабинет заказчика
- Регистрация и аутентификация через Zitadel (OIDC)
- Создание и отправка брифа
- Просмотр этапов проекта и загруженных материалов
- Принятие/отклонение результатов каждого этапа
- Оплата этапов через T-Bank
- Чат с командой внутри заказа и внутри этапа

### Кабинет специалиста
- Многошаговый онбординг: анкета, интервью, изучение регламентов, договор
- Рабочий кабинет: доступ к заказам, загрузка файлов по этапам
- Портфолио с аннотациями и аватар из портфолио
- Поле «О себе» (bio) в профиле
- Видимость на лендинге (флаг featuredOnLanding)
- Чат с администратором и заказчиком

### Кабинет администратора
- Управление онбордингом специалистов: одобрение/отклонение каждого шага
- Назначение специалистов на заказы
- Модерация этапов: одобрение или возврат на доработку с комментарием
- Выставление рейтинга специалисту
- Управление флагом «На лендинг»

### Проектный процесс — 5 этапов
- Концепция
- Планировка
- Визуализация
- Рабочая документация
- Спецификация материалов

Этапы идут последовательно. На каждом этапе: специалист загружает файлы, администратор модерирует, заказчик принимает или отправляет на доработку.

### Правки
- До 3 бесплатных раундов правок от заказчика на этап; сверх лимита — дополнительная оплата
- 1 бесплатный раунд правок от модератора на этап; сверх лимита — дополнительная оплата

### Акты и оплата
- Акт выполненных работ создается автоматически при приемке каждого этапа
- Предоплата за этап удерживается на платформе и выплачивается специалисту после приемки
- Интеграция с T-Bank: инициация платежа, webhook-уведомления, статусы

### Инфраструктура
- Email-уведомления на каждом переходе статуса (Resend/Nodemailer)
- In-app уведомления
- Мониторинг ошибок (Sentry)
- Лендинг с каруселью специалистов
- Docker Compose, Next.js standalone — готово к деплою
- GitLab CI: lint, тесты, сборка Docker-образа

## Этап 2 (план)

| Функциональность | Описание |
|-----------------|---------|
| Электронная подпись (ЭДО, СБИС) | Подписание актов и договоров в электронном виде |
| Квалификационный тест на платформе | Тест в интерфейсе без Zoom; автоматическая проверка |
| Рейтинги от клиентов | Клиент оставляет оценку после завершения проекта |
| Каталог специалистов с фильтрами | Поиск по специализации, городу, рейтингу |
| Автоматические выплаты (T-Bank Payout) | Выплата специалисту без ручного подтверждения |
| Видео-визитки специалистов | Загрузка и отображение видеопрезентации специалиста |
| PDF-генерация итоговых актов | Автоматический PDF при завершении проекта |
| Чек-лист замечаний модератора | Библиотека типовых замечаний по каждому этапу |
| Каруселью лендинга из БД | Специалисты в карусели загружаются динамически из БД |
